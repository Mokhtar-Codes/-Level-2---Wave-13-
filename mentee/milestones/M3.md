## Rules

1. **Change the data → save → render.** Every time, in that order.
2. **Loading and error states are data.** If you're setting `textContent` outside `render`, stop.
3. **Only what we've covered — Sessions 1 to 10.**
4. `fetch` or `axios`, your choice — but be ready to explain how the other one would differ.

## When you're stuck

The five bugs everyone hits, in the order they usually appear:

1. **Crash on a fresh browser** → no first-visit check. `getItem` gave `null`
2. **`Unexpected token ... is not valid JSON`** → something was saved without `JSON.stringify`, and the broken value is still in storage. Delete the key in Application and try again
3. **`Promise { <pending> }`, or your data's properties are `undefined`** → a missing `await`. There are **two** in a `fetch` call
4. **Nothing happens and there's no error** → look for `await` in a function that isn't `async`, or a `.catch` that swallowed it. Check the console
5. **"Loading…" forever** → the code threw before the message got reset. That's what `try/catch` is for
