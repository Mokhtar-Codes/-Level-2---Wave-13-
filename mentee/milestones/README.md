# Milestones — what each file is for

Your app is **one project, built in three stages**. The help you get shrinks each time.

---

## Start here

**`expense-tracker-starter/`** — your app.

Copy this folder into **your own repo** as `expense-tracker/`, once, at session 4. Everything you do for M1, M2 and M3 happens inside it. You never copy it again.

```
your-repo/
  expense-tracker/     ← copied from here, then it's yours
    app.js
    index.html
```

---

## The question everyone asks

**"Do I replace my `app.js` with the M2 skeleton?"**

**No.** At session 7 you already have working M1 code. The skeleton shows you where the new pieces go *around* what you've written — the four sections, and what belongs in each.

Open it beside your own file and compare. If your code has sections it doesn't, or the other way round, that's worth a minute's thought before you keep building.

---

## Why the help shrinks

M1 gives you a complete example. M2 gives you a skeleton. M3 gives you a description and nothing else.

That's deliberate. By session 11 you should be able to start from an empty folder — which is exactly what React will expect of you.
